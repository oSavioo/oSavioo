## Arthur Savio

Trabalho com migração de dados para SAP S/4HANA: puxar dado de sistema legado, tratar no ETL e carregar no destino sem quebrar nada no caminho.

No projeto em que estou hoje, construo as extrações no Pentaho, escrevo as regras de transformação em SQL e cuido do controle de pendências de mapeamento entre a equipe funcional e a de dados.

Gosto de problema de dado bagunçado: origem mal documentada, campo que muda de tipo no meio do caminho, carga que precisa bater com o destino no fim.

**Ferramentas do dia a dia:** Pentaho Data Integration · SQL Server · SAP HANA · SAP Cloud ALM · Migration Cockpit · Python

**Por aqui:** projetos e anotações minhas, nada com dado ou informação de cliente. Se algo for útil para você, pode usar.
